An interactive play-along tutorial to be used as a companion to the actual tabletop game. This tutorial allows you to learn the game while you play!

OBJECT

To WIN each Prisoner must:

  • Collect a key
  • Find the gate
  • Follow movement rules
  • Assemble with key at one gate

to unlock the gate and escape The Night Cage together.

Prisoners LOSE if:

  • All 4 Gate Tiles are lost
  • Keys cannot be collected
  • They can’t reach the gate together
